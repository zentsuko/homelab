# Homelab project source preview

This is a curated source snapshot containing Docker deployment manifests and
selected project source under `docker/`, plus selected Python projects from
`/opt` under `opt/`.

Runtime configuration, `.env` files, databases, logs, backups, virtual
environments, media, and service state are intentionally excluded. This source
snapshot is not a complete recovery backup of the homelab.

Only reviewed project sources are included; runtime configuration and personal
data remain excluded. This is not a complete recovery backup of the homelab.
