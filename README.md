# Homelab project source preview

This is a local, curated snapshot prepared for review before any GitHub upload.
It contains Docker deployment manifests and selected project source under
`docker/`, plus selected Python projects from `/opt` under `opt/`.

Runtime configuration, `.env` files, databases, logs, backups, virtual
environments, media, and service state are intentionally excluded. This source
snapshot is not a complete recovery backup of the homelab.

Review every file before publishing. No commit or push has been made.
